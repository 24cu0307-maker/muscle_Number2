============================================================
Conditional Effect 使用可能Condition一覧
更新日: 2026/08/31
============================================================

1. 標準で使用できる値
------------------------------------------------------------

time
  BGMの現在再生時刻（秒）です。
  VoltageBgmSystemが見つからない場合は、Scene開始からの経過秒数です。

score
  現在のスコアです。
  ScoreManagerが見つからない場合はGameSession.Scoreを参照します。

voltage
  VenueVoltageSystemの現在のVoltageです。
  VenueVoltageSystemが見つからない場合は0です。

値の名前は大文字・小文字を区別しません。
例: time、TIME、Timeは同じ値として扱われます。


2. 使用可能な比較演算子
------------------------------------------------------------

>    左の値が右の値より大きい
>=   左の値が右の値以上
<    左の値が右の値より小さい
<=   左の値が右の値以下
==   左右の値が等しい
!=   左右の値が等しくない

記述例:

time >= 30
score > 10000
voltage <= 50
score != 0


3. 使用可能な論理演算子
------------------------------------------------------------

&    AND。左右の条件を両方満たした場合
|    OR。左右の条件のどちらかを満たした場合
( )  括弧内を優先して評価

評価順序は、括弧、&、| の順です。

記述例:

time >= 30 & score >= 10000
score >= 10000 | voltage >= 80
(time >= 30 | score >= 10000) & voltage >= 50

「&&」と「||」には対応していません。
ANDは「&」、ORは「|」を一文字で入力してください。


4. タイムライン配置時刻
------------------------------------------------------------

Music Node EditorでConditional Effectモードを選択し、
タイムラインをクリックするとUse Timeline Timeが有効になります。

配置時刻はCondition欄とは別の条件として扱われ、
配置時刻に到達し、かつCondition欄も成立した場合に再生します。

例:

Timeline Time: 30
Condition: score >= 10000

結果:
30秒を過ぎ、かつスコアが10000以上になった時点で再生します。

時刻だけで再生する場合は、Conditionを次のまま使用できます。

time >= 0


5. 任意のCondition値
------------------------------------------------------------

標準値以外の数値もConditionalEffectManagerへコードから登録できます。

登録・更新:

conditionalEffectManager.SetValue("combo", comboCount);

同名値を登録または更新:

conditionalEffectManager.RegisterValue("audience", audienceValue);

現在値へ加算:

conditionalEffectManager.AddValue("combo", 1.0f);

登録後のCondition例:

combo >= 10
combo >= 10 & audience > 50

未登録の名前をConditionへ記述すると、Consoleへ警告が表示され、
その条件付き演出は再生されません。


6. 数値の記述
------------------------------------------------------------

整数、小数、負数を使用できます。

例:

score >= 10000
voltage >= 50.5
customValue > -1

小数点には半角の「.」を使用してください。


7. 現在使用できない記述
------------------------------------------------------------

- 加算、減算、乗算、除算などの計算式
  例: score + 100 > 10000

- NOT演算子
  例: !condition

- bool文字列
  例: true、false

- 「&&」「||」による論理演算

- 値だけの条件
  例: score

すべての条件には比較演算子と左右の値が必要です。


8. 発火設定
------------------------------------------------------------

Enabled
  OFFの場合は条件を評価せず、演出も再生しません。

Trigger Once
  ONの場合は条件成立時に一度だけ再生します。

Repeat Interval
  Trigger OnceがOFFの場合に、次回再生まで待つ秒数です。
  条件が成立し続けている場合は、この間隔で繰り返し再生します。
